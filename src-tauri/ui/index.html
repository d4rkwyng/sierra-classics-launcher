Sierra Classics Launcher

Version 2.0.0

Original Author: Derek Wood

Originally Created: June 2, 2007

This program was designed as a customizable front-end launcher for vintage Sierra games, allowing configuration for DOSBox, ScummVM, or custom game launches.
